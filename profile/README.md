# Dotablaze Tech

Community apps and bots, built in Go and run on Kubernetes.

| Repo | What it is |
|---|---|
| [platform](https://github.com/dotablaze-tech/platform) | Nx monorepo of the apps, services and libraries, including [Meow Bot](https://github.com/dotablaze-tech/platform/tree/main/apps/go/meowbot) for Discord |
| [deployments](https://github.com/dotablaze-tech/deployments) | Helm charts and Argo CD config that deploy them |
