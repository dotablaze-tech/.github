# dotablaze-tech

Dotablaze Tech: a Go and Nx monorepo for Discord bots and services, deployed to Kubernetes through GitOps.

## Repositories

| Repo | Description |
|------|-------------|
| [apps](https://github.com/dotablaze-tech/apps) | Nx and Go monorepo: apps, libraries and tooling, including the meowbot Discord bot |
| [deployments](https://github.com/dotablaze-tech/deployments) | Helm charts and ArgoCD app definitions for the dotablaze-tech tenant |
